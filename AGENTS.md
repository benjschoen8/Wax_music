# AGENTS.md — Contributor & Agent Guide for Wax

Wax (formerly Crate) is an offline music downloader and player built with Flutter, targeting Android and cross-platform desktop. It searches YouTube and YouTube Music, downloads audio streams, embeds metadata/cover art via FFmpeg, fetches synchronized lyrics (.lrc), manages offline playlists and local library storage (MediaStore), and provides background audio playback.

---

## 1. Quick Reference Commands

Always verify your changes before committing:

```bash
# Static analysis (must maintain 0 errors in lib/)
flutter analyze

# Run unit and architectural tests
flutter test

# Run a specific fast unit test file (no network needed)
flutter test test/clean_title_test.dart
flutter test test/round2_security_test.dart
flutter test test/local_storage_scan_test.dart

# Build Android APK
flutter build apk --release
```

> **Note on tests**: Tests in `test/` include both hermetic unit tests and live network integration tests (e.g., testing live YouTube Music / LRCLIB / NetEase responses). Isolated unit tests always pass; live tests may be skipped or subject to upstream network availability.

## 3. Strict "Do Not Read / Do Not Touch" List

To conserve context tokens and prevent context contamination:

1. **`third_party/`** (~1,400 AST symbols):
   - Contains a vendored snapshot of `youtube_explode_dart`.
   - **Never read or edit files in `third_party/`**. Treat it as a black box. Access YouTube exclusively through existing facades in `lib/downloader.dart`, `lib/ytm_search.dart`, or future adapter seams.
2. **`graphify-out/graph.json` & `graphify-out/graph.html`** (~2.3 MB each):
   - **Never read or dump these files into agent context**.
   - If querying the knowledge graph, read `graphify-out/GRAPH_REPORT.md` (summary report) or use `graphify query "<question>"`.
3. **Generated files (`*.freezed.dart`, `*.g.dart`)**:
   - Machine-generated by build_runner. Do not inspect unless debugging code-gen errors.
4. **`build/`, `.dart_tool/`, `android/`**:
   - Standard Flutter/Gradle build caches. Do not inspect unless modifying native Android manifests.

## 4. Coding Conventions & Architecture Guardrails

### Flutter UI & Widget Performance
- **Extract Widget Classes, Not Helper Methods**: Break up large `build()` methods by creating private `StatelessWidget` / `StatefulWidget` classes (e.g. `class _FilterBar extends StatelessWidget`) rather than `Widget _buildFilterBar()`. Helper methods bypass Flutter's build caching and cause full-tree rebuilds.
- **Target File Size**: Aim for ~300 lines per file. Files exceeding 800 lines should be split into domain-specific sub-widgets or controllers.

### State Management & Hot Paths
- **Avoid Global Rebuild Blasts**: Do not call `notifyListeners()` on the entire `AppState` for localized events.
- **Hot-Path Player Isolation**: `WaxAudioHandler` listens to `Preview`. Ensure high-frequency updates (e.g. playback position) use dedicated `ValueNotifier` or streams, avoiding full re-syncs of metadata and queue items.
- **Dependency Inversion**: Pass specific controllers or domain notifiers (`LibraryState`, `QueueState`, etc.) into widgets rather than passing the monolithic `AppState`.

### Logging & Security
- **Never use `print()` in production code**: Use `AppLog.info()`, `AppLog.warning()`, or `AppLog.error()`.
- **Sensitive Data**: `AppLog` automatically redacts session cookies (`SAPISID`, `SSID`, `LOGIN_INFO`) and download signature tokens. Never disable this redaction.
